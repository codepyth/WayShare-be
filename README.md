# WayShare — Backend

REST API for **WayShare**, a peer-to-peer intercity ride-sharing platform for the UK. Drivers
already making a journey offer their empty seats; passengers share the running cost.

Built with **Python, Django and Django REST Framework**, with PostgreSQL and an OpenAPI
contract generated from the code.

> 🚧 **Status: in active development** — foundations phase. The API surface is being built now.

---

## Tech stack

| Area | Technology |
|---|---|
| Language | Python 3.14 |
| Framework | Django 6.1 + Django REST Framework 3.18 |
| Database | PostgreSQL (SQLite fallback for early local work) |
| API contract | OpenAPI 3, generated by `drf-spectacular` and committed as `openapi.json` |
| Auth | Django session authentication, Argon2 password hashing |
| Config | Environment variables via `django-environ` |
| Frontend (planned) | Next.js, with TypeScript types generated from `openapi.json` |

## Engineering principles

- **Money in integer pence**, never floats.
- **Timestamps stored in UTC**, displayed in `Europe/London`.
- **UUID primary keys**, plus short human-readable references for anything users see.
- **Soft delete** and an **audit log** on every state change.
- **Deny by default** — every endpoint requires authentication unless it explicitly opts out.
- **The server owns every business rule**; the frontend only displays them.
- **No secrets in the repository** — all configuration comes from the environment.

## Getting started

Requires Python 3.14+.

```bash
python -m venv .venv
source .venv/Scripts/activate        # Windows Git Bash  (macOS/Linux: source .venv/bin/activate)

pip install -r requirements.txt
cp .env.example .env                  # then set DJANGO_SECRET_KEY
python manage.py migrate
python manage.py runserver            # http://127.0.0.1:8000/
```

Generate a secret key with:

```bash
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

## API documentation

With `DJANGO_DEBUG=true`:

- `/api/docs/` — Swagger UI
- `/api/schema/` — raw OpenAPI schema

Regenerate the committed contract after any API change:

```bash
python manage.py spectacular --format openapi-json --file openapi.json --validate
```

## Project structure

```text

├── wayshare_backend/      # settings, URLs, WSGI/ASGI
```
